## 设计决策

整体像一份轻盈的心动小问卷：浅蓝灰底，白色问答卡，浅粉只出现在品牌和少量标记中。大面积正文下方保持稳定纯色；所有标题改用清楚的系统黑体。蓝紫色强调用于交互反馈与重要信息，不使用酒红。

签名图案是“心形对话框”：一个圆润对话框包着心形，直接表达 AI 互动与心动。首页、品牌栏、解析页使用同一个本地 SVG，分享卡用相同形状绘制。移除抽象轨道、点阵和不具含义的英文标记。

| 角色 | 值 |
| --- | --- |
| 页面背景 | #F5F7FC |
| 卡片表面 | #FFFFFF |
| 正文 | #30374D |
| 强调 / 次级文字 | #626DB2 / #7B8399 |
| 浅粉 / 浅蓝 | #FFF0F6 / #EDF2FF |
| 边框 | #E7EBF4 |

标题：PingFang SC / Microsoft YaHei / 系统黑体，粗细 650–700；正文同一字体、常规字重。数字用系统无衬线并开启等宽数字。保留离线字体栈。

```text
首页                         答题页
品牌                         返回                 品牌
                             当前题数 + 作答提示
       浅粉说明标签           ━━━━━━━ 进度
        两行主标题           ╭─────────────────────╮
       心形对话框图案        │ 第 1 题              │
        三行介绍文字         │ 当前问题              │
                             │ ╭ A · 选项 ───────╮ │
        时长提示             │ ╭ B · 选项 ───────╮ │
      开始测试按钮           │ ╭ C · 选项 ───────╮ │
        娱乐说明             │ ╭ D · 选项 ───────╮ │
                             ╰─────────────────────╯
                              可返回修改的说明
```

390px 基准：页面边距 20px；品牌 13px；首页标题 32px/1.5；问题 23px/1.55；选项 14px/1.75。答题卡 28px 圆角、内边距 22px；选项 18px 圆角、最小 76px 高；主按钮 18px 圆角、58px 高。窄屏按真实文本换行，末题允许自然滚动。

结果：白色人格卡 + 阅读正文，粉色标记和浅蓝关键词标签；指标版保持真实数值的清晰层级。分享卡 1080×1440，以同一字体、图标和卡片结构呈现。

## 细节审查

| Before | After | Why |
| --- | --- | --- |
| 大面积粉蓝渐变与宋体标题 | 浅蓝灰纯色底 + 清晰黑体 | 减少正文阅读干扰 |
| 抽象轨道图与不一致的品牌符号 | 同一心形对话框 SVG | 让图案表达产品主题 |
| 题目直接散落在背景上 | 集中的白色答题卡 | 固定每题视觉节奏 |
| 点击选项出现常驻焦点圈 | 触控显示选中态，键盘保留焦点 | 避免误把焦点当选中 |
| 全页面位移动效 | 短淡入与轻按反馈 | 保持流畅且不拖慢答题 |
