# 手机离线预览

`AI心动人格测试-手机离线预览.html` 是额外提供的单文件浏览器预览：样式、脚本和图形全部在这一份文件中，不需要电脑、Wi-Fi、服务器或外部资源。问卷与算法直接复用项目源码，没有调整评分。

当前为 V2，共 18 道题，包含独立的 AI 配置档案。浅蓝与浅粉分别使用对应名称的 HTML；旧版文件和记录保留，新版需要重新答题。

这份文件用于手机浏览器测试，内嵌脚本不符合小红书容器要求。**Builder Hub 仍然上传单独的 `ai-heart-personality-v2.0.0.zip` 或浅粉版 ZIP，不要上传这份 HTML。**

## Android

将 HTML 文件通过 USB、文件传输或网盘下载到手机。用文件管理器选择“打开方式”，选择能运行本地 HTML / JavaScript 的浏览器或 HTML 查看器。不要在聊天软件附件预览中测试。

不同品牌的文件管理器、浏览器和权限策略可能不同。如果只能看到源码、预览文字或按钮不响应，说明打开的程序没有执行 JavaScript；需要换用支持脚本的本地 HTML 查看器。并非每个 Android 浏览器都接受文件管理器传来的本地文件。

## iPhone

下载并保存到“文件”App 可以保留该离线文件，但内置文件预览不能保证运行 JavaScript 问卷。不要把能看到文件预览视为能完整运行问卷。

建议使用 [HTML查看器 - Sitecase](https://apps.apple.com/cn/app/html%E6%9F%A5%E7%9C%8B%E5%99%A8-sitecase/id6762896369)。其 App Store 产品说明列明支持本地 HTML、CSS、JavaScript 和离线使用，可从“文件”App 或共享菜单导入。当前页面注明需要 iOS 17.6+，免费下载安装、包含可选内购；本次提供的是单文件，不需要导入多文件项目。

1. 把 `AI心动人格测试-手机离线预览.html` 通过文件传输或网盘送到 iPhone，保存到“文件”。
2. 安装上述查看器，在查看器内导入这份 HTML；或在“文件”里对它使用共享菜单，选择查看器打开。
3. 在查看器里运行页面，可打开飞行模式验证完整答题和结果卡。

此建议依据开发者在 App Store 的功能说明，尚未在用户手机或该 App 内实测。没有声称 iPhone 内置 Safari 或“文件”App 能直接完整打开此问卷。

若不希望安装查看器，可以使用小红书平台的小工具模拟器 / 真机扫码预览官方 ZIP；这属于容器运行，问卷本身仍是离线的。分享草稿、相册保存等小红书端能力也应在那里测试。

## 核验

单文件在本机浏览器断网、file URL 环境执行完整 15 题并生成 Canvas 分享图。尚未在用户的具体手机或本地 HTML 查看器上实测；手机系统 / 查看器可能限制本地缓存，页面已处理缓存失败。
