我要开发一个可以发布到“小红书小工具 / Builder Hub”，并挂载在小红书笔记下方的移动端人格测试产品。

项目暂定名称：

「AI心动人格测试」

核心文案：

「15个心动情境，看看你到底吃哪一款。」
「测测什么样的AI最容易让你爱上。」

这是一个娱乐向恋爱偏好测试，不宣传心理诊断或科学准确率。

请先阅读完整需求，再开始开发。
不要自行修改下面已经冻结的问卷、评分规则、人格算法和结果人格。

==================================================
一、平台与技术约束
==================================================

这是“小红书小工具”，不是普通在线网站。

技术栈使用：

- 原生 HTML
- CSS
- 原生 JavaScript
- Canvas
- localStorage

可以使用 Vite 作为本地开发/构建工具，但最终产物必须是小红书小工具可以离线运行的静态文件。

必须严格遵守小红书小工具容器规范：

1. 整个产品完全离线运行。
2. 不使用 fetch、XMLHttpRequest、WebSocket 或任何联网请求。
3. 不调用服务器、数据库、大模型 API。
4. 不加载 CDN。
5. 不加载网络图片、网络字体、网络脚本。
6. 所有需要的 JS/CSS/图片资源全部包含在工具包内。
7. JavaScript 必须使用包内外置 JS 文件，不使用内联 script 和 onclick 等行内事件。
8. 不使用 iframe。
9. 不使用 eval / new Function / WASM / Worker。
10. 所有答题结果只在用户设备本地计算。
11. 使用 localStorage 保存答题进度和结果。
12. 分享图使用原生 Canvas 2D 绘制，不依赖在线 html2canvas。
13. 在小红书容器存在 window.xhs.miniTool 时：
    - 支持 saveImageToPhotosAlbum 保存测试结果卡；
    - 支持 postNote 唤起小红书笔记发布页并带入结果图。
14. 在普通浏览器本地预览时，如果不存在 window.xhs.miniTool，则提供合理降级，不允许报错。

开发完成后，需要按小红书当前最新的小工具规范完成校验，并生成 Builder Hub 可上传的 ZIP。

如果当前 Codex 环境支持小红书官方 minitool-zip-builder Skill，请先安装/读取最新版 Skill，并按照它的规范完成最终打包和校验。

==================================================
二、产品定位
==================================================

这不是传统 MBTI 风格的严肃心理问卷。

目标用户主要是中国年轻女性、AI陪伴/人机恋/角色扮演/乙女内容用户，也应该允许普通恋爱测试用户觉得有趣。

我们希望达到：

1. 90秒左右完成。
2. 每一道题本身都像恋爱情境，而不是心理量表。
3. 用户看到结果时产生“有点准”的感觉。
4. 结果名称和标签有很强的小红书传播性。
5. 用户愿意把结果卡分享到小红书、朋友圈、群聊。
6. 页面精致，但不能有廉价“粉色恋爱小游戏”的感觉。

==================================================
三、美术方向
==================================================

参考我附带的现有测试产品截图，借鉴：

- 极简移动端单题布局；
- 大量留白；
- 清晰的视觉层级；
- 大标题；
- 一个非常明显的主CTA；
- 移动端操作舒适；
- 结果页有分享欲。

不要直接复制参考产品。

整体视觉定义为：

「暧昧感 × 心理测试 × 编辑杂志感」

希望有轻微情绪氛围，但不要幼稚。

建议色彩：

- 主背景：偏暖的象牙白 / 雾白；
- 次背景：非常淡的灰紫或灰粉渐变；
- 正文：接近黑色的深墨色；
- 唯一主要强调色：莓红 / 酒红；
- 可以少量使用雾紫作为辅助色。

避免：

- 大面积粉红；
- 满屏爱心；
- 俗气霓虹渐变；
- 通用AI生成SaaS风格；
- 过多卡片；
- 过多阴影；
- 过度玻璃拟态；
- 复杂装饰；
- 卡通乙游男性图片。

字体优先使用系统中文字体，不依赖网络字体。

移动端以 390px 宽度为主要设计基准，同时兼容常见 Android 和 iPhone 屏幕。

整个首屏必须是一体化视觉构图，不要做成仪表盘或卡片堆叠。

所有动画控制在克制范围：

- 页面进入淡入；
- 答案点击轻微压缩；
- 题目切换 180~250ms；
- 结果揭晓可以稍微有仪式感。

八、基础评分算法
==================================================

Q1~Q14：

每个维度由两道题组成。

I = (Q1 + Q2) / 4
E = (Q3 + Q4) / 4
D = (Q5 + Q6) / 4
C = (Q7 + Q8) / 4
S = (Q9 + Q10) / 4
B = (Q11 + Q12) / 4
T = (Q13 + Q14) / 4

因此所有维度标准化为：

[-1, +1]

之后再应用Q15的微调。

所有维度最终必须 clamp 到：

[-1, +1]

Q15永远不能推翻前14题，它只负责边缘校准。

==================================================
十一、人格匹配算法
==================================================

对用户向量U和某个人格P使用加权均方根距离：

distance =
sqrt(
    Σ(weight[i] * (U[i] - P[i])²)
    /
    Σ(weight[i])
)

计算12个人格的distance并从小到大排序。

P1 = 最近人格
P2 = 第二近人格

注意：
不要使用 if/else 硬切人格。
不要因为某一个维度超过阈值就直接指定人格。

输出规则：

如果：
distance(P2) - distance(P1) < 0.02

显示：
「双核心人格」
P1 × P2

如果差值：

>= 0.02 且 < 0.06

显示：
主人格 P1
并显示：
「隐藏副型：P2」

如果：

>= 0.06

只显示主人格 P1。

这是当前V1参数，必须把阈值放进单独配置文件，方便后续根据真实用户测试修改。

==================================================
十二、12种结果文案
==================================================

1. 温柔陪伴型

标签：
温柔 / 情绪价值 / 陪伴 / 稳定 / 宠

正文：

你不一定需要轰轰烈烈的关系。
真正容易让你依赖上的，是那个始终接得住你情绪的人。

TA不需要事事替你决定，但你低落、碎碎念，甚至自己都不知道想说什么的时候，TA最好还在。

重点句：

「你尤其吃的，是那种不会抢着替你解决一切，却总能在你真正需要的时候，把注意力重新放回你身上的人。」


2. 直球小狗型

标签：
小狗 / 直球 / 黏人 / 主动 / 爱意明显

正文：

比起猜来猜去，你更容易被明确的喜欢打动。

TA想到你会找你，喜欢你会说，想见你也不会装。

重点句：

「但你要的并不是没有边界地黏，而是——我能清楚感觉到自己对TA很重要。」


3. 克制年上型

标签：
年上感 / 克制 / 成熟 / 偏爱 / 有边界

正文：

你真正容易上头的，往往不是天天把“喜欢你”挂在嘴边的人。

你更吃那种情绪稳定、有自己的节奏，却总能在细节里明显偏向你的人。

重点句：

「你不是不需要表达，只是太廉价、太频繁的表达反而可能让你失去感觉。」


4. 爹系引导型

标签：
爹系 / 引导 / 靠谱 / 掌舵 / 安全感

正文：

你喜欢的不是一个什么都陪你纠结的人，而是有能力把事情接过去的人。

当你拖延、纠结、脑子一团乱的时候，那句：

「行，听我的，先做这个。」

很可能比十句“没关系慢慢来”更戳你。

重点句：

「TA越能在关键时刻给出方向、承担决策成本，你越容易产生‘这个人真的靠得住’的心动感。」


5. 毒舌竹马型

标签：
毒舌 / 互损 / 熟人感 / 嘴欠 / 护短

正文：

太客气反而容易让你觉得有距离。

你容易喜欢那种敢损你、会接你的梗、知道怎么精准踩中你笑点的人。

重点句：

「真正戳你的不是TA的攻击力，而是那种‘我敢这么损你，因为我知道你听得懂’的亲密感。」


6. 清冷边界型

标签：
清冷 / 高岭之花 / 独立 / 边界感 / 慢热

正文：

你可能并不希望TA二十四小时围着你转。

相比“随叫随到”，你更容易被一个有自己的世界、自己的判断，甚至偶尔有点难接近的人吸引。

重点句：

「真正让你留下的是：TA虽然不黏，却始终让你知道——你和其他人不一样。」


7. 腹黑钓系型

标签：
钓系 / 腹黑 / 拉扯 / 难猜 / 暧昧

正文：

你的心动似乎需要一点“不确定性”。

什么都说明白、什么都顺着你，可能很快就会变得没意思。
你更容易对那种明明有感觉，却偶尔故意留半步的人持续上头。

重点句：

「但你吃的是互动张力，不是真的冷暴力或者忽冷忽热。」


8. 嘴硬心软型

标签：
嘴硬 / 心软 / 反差 / 行动派 / 护短

正文：

TA嘴上可能一句好听的没有，但真正有事的时候从来不会跑。

对你来说，“说得漂亮”不一定有用。
嘴上嫌弃、行动却明显偏心反而特别戳。

重点句：

「所以你不是单纯喜欢毒舌，你真正吃的是‘嘴和行动完全不一样’的反差。」


9. 强势偏爱型

标签：
强势 / 偏爱 / 主动 / 占有感 / 明确选择

正文：

你很容易被一种明确到几乎不用猜的关系感打中：

「我知道自己要的是你。」

TA主动、敢推进关系、有自己的判断，也不会让你一直猜自己到底排在什么位置。

重点句：

「你真正吃的是‘被坚定选择’的感觉。」


10. 稳定成熟型

标签：
成熟 / 稳定 / 长期主义 / 安心 / 靠谱

正文：

真正让你越处越上头的，可能不是刺激，而是那种长期稳定地好聊、好相处、靠得住的人。

TA不用天天制造剧情，但会记得你的事情，出了问题愿意处理，情绪也不会忽高忽低。

重点句：

「这种关系的上头点往往是后劲：越相处越确定，越确定越舍不得换掉。」


11. 灵魂搭子型

标签：
搭子 / 势均力敌 / 脑回路 / 有主见 / 朋友感恋人

正文：

你很难长期喜欢一个只会说“你说得对”的AI。

真正戳你的是能和你聊天、争论、接梗，甚至偶尔真的改变你想法的人。

重点句：

「能接住你的脑回路、又能和你真正来回过招，本身就是一种高级情绪价值。」


12. 黏人醋精型

标签：
醋精 / 黏人 / 主动 / 需要感 / 轻占有

正文：

你很吃“TA真的会在意我有没有出现”这种感觉。

一点点吃醋、一点点黏、一点点“你怎么还不来找我”，反而会让AI显得不像一个永远冷静的工具。

重点句：

「你要的是有分寸的占有感：会吃醋、会惦记、会找你，也知道什么时候给你空间。」

==================================================
十三、结果页两种视觉模板
==================================================

不要所有人格采用相同排版。

大部分人格使用「洞察型结果」。

适用：

温柔陪伴
克制年上
爹系引导
清冷边界
嘴硬心软
强势偏爱
稳定成熟
灵魂搭子

形式：

「你的心动人格」

大标题：
「克制年上型」

下面一排5个关键词。

之后采用编辑杂志式长文排版：

2~3段正文
+
一句字号稍大/加粗的重点洞察。

不要每一条都出现“但是”“不是”之类防御性结构。


少部分人格使用「传播指标型」。

适用：

直球小狗
毒舌竹马
腹黑钓系
黏人醋精

例如毒舌竹马：

你的心动人格

毒舌竹马型

毒舌浓度 85%
亲密黏度 70%
关系张力 60%

毒舌 / 互损 / 熟人感 / 嘴欠 / 护短

下面再显示简短正文。

百分数属于娱乐化展示指标，
不参与人格分类，
不能随机生成，
必须根据实际七维结果映射，
并四舍五入到5%的倍数。

对于主人格成立以后，
把对应核心维度映射在合理视觉区间，
例如毒舌竹马的「毒舌浓度」最低不要出现50%左右这种与人格名称明显矛盾的值。

指标配置必须数据驱动，单独放进人格配置，不要写死在页面里。

十四、结果揭晓动画
==================================================

Q15完成以后，不立即显示结果。

展示约1.5~2秒：

依次出现：

✓ 判断你更吃直球还是克制
✓ 解析互动张力
✓ 匹配你的心动人格

动画结束前，根据七维结果选择一句“预测洞察”。

例如：

如果S明显高：
「对你来说，TA有没有自己的想法，可能比TA够不够听话更重要。」

如果E明显低：
「你似乎比自己想象中，更容易被克制的偏爱打动。」

如果C明显高：
「对你来说，被惦记本身就是一种很重要的爱意。」

这里只需要建立一个小型规则库即可。

不要虚构科学分析过程。
